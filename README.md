
# Alien Attack

Alien Attack - 2D-игра на MonoGame, в которой один или два игрока сражаются с волнами инопланетных мобов. Враги появляются справа, двигаются к ближайшему живому игроку, стреляют и наносят урон при столкновении. Игроки получают очки за уничтожение врагов.

## Возможности

- режим на 1 или 2 игроков;
- движение игроков по левой части карты;
- стрельба игроков и врагов;
- мобы автоматически идут к ближайшему живому игроку;
- начисление очков за убийство врагов;
- отображение управления, счета, времени и здоровья во время игры;
- экран окончания игры с итоговым счетом;
- сохранение результатов в таблицу рекордов;
- главное меню, экран рекордов и настройки звука.

## Управление

### Игрок 1

- `W`, `A`, `S`, `D` - движение;
- `Space` - выстрел.

### Игрок 2

- `Up`, `Down`, `Left`, `Right` - движение;
- `Enter` - выстрел.

### Общие клавиши

- `Esc` - выход из игры;
- на экране окончания игры:
  - `Enter` - перейти к рекордам;
  - `R` - начать заново.

## Правила игры

Цель игры - продержаться как можно дольше и набрать больше очков. Мобы появляются с правой стороны экрана и идут к игрокам. За каждого убитого моба игрок получает 1 очко.

Игра заканчивается, когда здоровье всех игроков становится равным нулю. После этого показывается итоговый счет и результат сохраняется в рекорды.

## Требования

- Windows;
- .NET SDK 6.0 или новее;
- MonoGame устанавливается через NuGet-пакеты проекта.

Проект использует:

- `MonoGame.Framework.DesktopGL`;
- `MonoGame.Content.Builder.Task`;
- `net6.0`.

## Как запустить

### Через командную строку

1. Откройте терминал в папке проекта.
2. Перейдите в папку игры:

```powershell
cd UlearnGame
```

3. Восстановите зависимости и соберите проект:

```powershell
dotnet restore
dotnet build
```

4. Запустите игру:

```powershell
dotnet run
```

### Через Rider или Visual Studio

1. Откройте файл решения `UlearnGame.sln`.
2. Выберите проект `UlearnGame` как стартовый.
3. Запустите проект кнопкой Run.

## Структура проекта

- `UlearnGame/Game1.cs` - основной класс MonoGame, переключение состояний игры;
- `UlearnGame/States` - игровые экраны: меню, игра, рекорды;
- `UlearnGame/Sprites` - игроки, враги, пули, взрывы и базовые спрайты;
- `UlearnGame/Managers` - менеджеры анимаций, врагов и счета;
- `UlearnGame/Models` - модели данных: ввод, счет, настройки звука, анимации;
- `UlearnGame/Content` - изображения, шрифты и звуки игры.

## Сборка

Для проверки проекта используйте:

```powershell
dotnet build
```

Если сборка проходит успешно, игра готова к запуску. Предупреждение про `net6.0` может появляться на новых версиях .NET SDK, потому что .NET 6 больше не получает обновления безопасности, но оно не мешает сборке проекта.
